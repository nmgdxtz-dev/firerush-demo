# 火力突围 V0.7 · 同心电路

原创双人护送射击：墨墨负责开火，咕咕用共振守住彼此。把能源车送过三段封锁区，击穿灯塔机甲。单局约 2.5–3.5 分钟，失败可立即重开。

## 试玩

- 开发版：`npm run dev`，打开 http://localhost:4173 。
- 独立试玩构建：`npm run build`，打开 `dist/index.html`；单文件无外部资源，可离线打开，也可部署到任何静态托管。
- 单指左右拖动，自动开火；按钮释放共振。键盘 A/D 或方向键移动，空格共振，P 暂停。失焦和切后台自动暂停。

每 4 次击破回收 1 电荷，重甲额外给 2。电荷在 18 / 40 / 70 时把双枪进化为三线、穿甲五线和七线。电荷也是支路补给与共振的费用；消费可能让武器退档。漏敌会损伤后方能源车，路障会挡弹，不能只盯着自己的碰撞。

六处岔路有 5 秒预告，按车头所在半边自动结算。界面显示当前值、算式、封顶后的结果和代价。费用不足会绕行并损伤 10 车体；可以在结算前换侧。警戒会增加追兵与追踪车道的光栅。封锁机甲先预告扫射，扫射后短暂暴露核心，闭合装甲只承受少量伤害。

## 验证

Node 22，无 npm 依赖。

- `npm test`：逻辑回归。
- `npm run balance`：固定种子 1–10 的自动策略回放，以及种子 12 的静止对照。策略只移动、选择路线、释放共振，不修改资源或敌人。这不代表真人通关率。
- `npm run dev` 后打开 `/tests/browser.html`：点击“运行浏览器检查”，验证浏览器内暂停/继续、触控指针、失败重开、六次路线和完整胜利流程；另有真实回放至路线与 Boss 的截图入口。
- CI 执行逻辑测试、平衡回放和构建，并上传单文件试玩 artifact。CI 状态应以 GitHub 实际运行结果为准。

## 架构与小游戏迁移边界

`src/game.js` 是无 DOM 的种子化模拟；`src/main.js` 是 Canvas 2D 渲染和浏览器输入/音效/存储适配；`style.css` 是菜单和可访问按钮。绘制均为原创程序图形，零图片、字体和音频下载。构建脚本仅内联本地源文件。

敌人上限 110、玩家子弹 190、敌弹 110、粒子 160；DPR 上限 2。单帧模拟步长限 40ms，低帧率下允许游戏减速而非突进。普通游玩不暴露调试接口；`?test` 显式开启回放钩子。

微信小游戏尚未接入：仍需把入口、Canvas、触摸、生命周期、存储、音频和菜单适配到小游戏宿主，并在低端安卓/iOS 真机测帧耗时、峰值内存和触控。当前包体小、逻辑可迁移，不等于已完成微信端兼容。
